# TecnoShop

Sitio web estático para la promoción de servicios de mantenimiento técnico,
activación de software y venta de accesorios de cómputo.

Proyecto formativo — Técnico en Sistemas Teleinformáticos, SENA Regional Caldas.

## Cómo ejecutar localmente

Al usar `fetch()` para cargar los archivos JSON del catálogo, abrir `index.html`
directamente con doble clic (protocolo `file://`) puede bloquear la carga por
la política CORS del navegador. Se recomienda levantar un servidor local
simple, por ejemplo:

- Extensión **Live Server** de VS Code, o
- `python -m http.server` desde la raíz del proyecto
